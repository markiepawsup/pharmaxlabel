❓ วิธีใช้งานโปรแกรมโดยสรุป

1. เลือกร้าน / สาขา

  • หน้าแรก: แตะโลโก้ร้าน แล้วพิมพ์รหัสสาขา 3 หลัก (เช่น 001) — ระบบเข้าหน้าฉลากให้เองเมื่อครบ 3 หลัก
  • มือถือ/แท็บเล็ต: กด 📍 หาสาขาใกล้ฉัน (หรือระบบหาให้อัตโนมัติ) — ถ้าอยู่ในร้านจะเลือกสาขาให้ทันที
  • เปลี่ยนสาขา: กดโลโก้มุมซ้ายบน หรือปุ่ม เปลี่ยนสาขา

2. หายาด้วยบาร์โค้ด

  • ยิงบาร์โค้ดได้ตลอด ไม่ต้องคลิกช่องก่อน — หรือพิมพ์รหัสสินค้า (Item No.) แล้วกด Enter
  • แท็บเล็ต/มือถือ: กดปุ่ม 📷 เพื่อสแกนด้วยกล้อง
  • ไม่พบยา? → กดปุ่มสีแดงเพื่อส่งข้อมูลยาใหม่ (ต้องเข้าสู่ระบบ) · ยาที่ส่งแล้ว 🔒 พิมพ์ได้ทันทีเฉพาะบัญชีคุณ ระหว่างรออนุมัติ และจะมีแจ้งเตือนเมื่ออนุมัติแล้ว

3. เลือกภาษา & ตรวจฉลาก

  • แถบปุ่มภาษา 16 ภาษา (ลากเรียงลำดับได้ ระบบจำไว้ในเครื่อง)
  • ยาที่มีหลายโรค (เช่น aciclovir) เลือกโรคในช่อง ใช้รักษาโรค — ขนาดยา/คำแนะนำเปลี่ยนตาม
  • วิธีใช้ที่ตาราง 4 ช่องแสดงไม่ได้ (ทุก 6 ชม., วันละ 5 ครั้ง, สัปดาห์ละครั้ง) ใส่ในช่อง ความถี่ / วิธีใช้พิเศษ
  • กล่องแจ้งเตือนใต้ฉลาก: 📘 ประโยคยังไม่อยู่ใน glossary (แปลอัตโนมัติ) · ⚠️ คำแปลรอตรวจ · ฉลากภาษาต่างประเทศที่ยังมีภาษาไทยปน ระบบจะถามก่อนพิมพ์
  • ปุ่มใต้ Preview: ซ่อน/แสดง โลโก้ · เวลาทำการ · วันที่

4. พิมพ์

  • ➕ เพิ่มเข้าคิว (F2) สะสมหลายรายการ แล้ว พิมพ์ทั้งหมดในคิว (F8) · 🖨️ พิมพ์ทันที (F4) เฉพาะใบนี้
  • ในคิว: − ×N + = จำนวนสำเนา · ✎ = นำกลับมาแก้ · 👤 ชื่อทั้งคิว = ใส่ชื่อผู้ใช้ยาให้ทุกรายการ
  • ติ๊ก พิมพ์ฉลากภาษาไทยเพิ่มด้วย เพื่อพิมพ์ใบไทยต่อท้ายทุกใบ · Esc = ล้างทั้งหมดเริ่มใหม่

5. ติดตั้งเป็นแอป / ใช้ตอนเน็ตช้า

  • iPad / iPhone (Safari): ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม · Android / PC (Chrome): เมนู ⋮ → ติดตั้งแอป
  • เปิดแล้วครั้งหนึ่ง เครื่องจะเก็บไฟล์โปรแกรมไว้ เปิดได้แม้เน็ตหลุด (ข้อมูลยาใช้ชุดล่าสุดที่ซิงค์ไว้) · มีเวอร์ชันใหม่จะมีแถบแจ้งให้กดรีเฟรช

📋 คู่มือคีย์ลัด & คำอธิบายสัญลักษณ์

⌨️ คีย์ลัด (Keyboard Shortcuts)

F2 หรือ Ctrl + Enter ➕ เพิ่มยาตัวนี้เข้าคิว
F4 หรือ Ctrl + P 🖨️ พิมพ์ฉลากนี้ทันที (ใบเดียว)
F8 หรือ Ctrl + Shift + P 🖨️ พิมพ์ทั้งหมดในคิว
F9 กลับไปช่องบาร์โค้ด (เลือกข้อความเดิมให้พิมพ์ทับ)
F1 วิธีใช้งาน
Esc ล้างทั้งหมด เริ่มรายใหม่ (บาร์โค้ด ฟอร์ม คำเตือน)
Ctrl + Z ย้อนกลับการแก้ไขฟอร์มยา (ทำซ้ำ: Ctrl + Y)
Tab / Space ยอมรับคำแนะนำข้อความเงา (Ghost Text)
Enter ในช่องขนาดยา: ไปช่องถัดไป
